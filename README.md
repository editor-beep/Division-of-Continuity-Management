# Division-of-Continuity-Management

## Run on Replit

This repository now includes a `.replit` configuration that:

1. installs the `godot_4` package and uses the `godot4` CLI
2. exports the Godot project to Web (`03_Tech/Godot_Project/build/web/index.html`)
3. serves the exported build on port `3000`
4. runs via `scripts/replit_run.sh`

On Replit, click **Run** to build and launch the playable web build.
