THE DIVISION OF CONTINUITY MANAGEMENT 03_UI_Visual_Guide.md (Official Visual Direction)

Overall Aesthetic
“Sacred Bureaucracy” — A decaying corporate terminal infused with living sacred geometry, breathing diagrams, and faint cosmic horror.
Think:
	•	Papers, Please × Control × Blade Runner 2049 × medieval illuminated manuscripts × Windows 95 CRT aesthetics
	•	A cathedral built inside a government office that is slowly becoming aware
Core Feeling: Beautiful but wrong. Orderly but alive. Comforting yet oppressive.

Color Palette
Primary:
	•	Deep Void Black (#0A0A0F)
	•	Warm CRT Amber/Gold (#FFB000 / #FFCC66) — for sacred elements
	•	Muted Teal/Cyan (#00B8B0) — for active fields and continuity threads
	•	Soft Off-White / Parchment (#F5EDE0) — text and forms
	•	Blood-Dark Maroon (#5C0010) — for warnings and high-stakes decisions
Accents:
	•	Faint pulsing purple (#8C4EFF) — mythic residue
	•	Desaturated greens for approval stamps
	•	Shifting greys that lean warmer or colder based on player Dissolution Index

Typography
	•	Headers: Elegant serif (like Garamond or a custom “bureaucratic liturgical” font) with subtle glow
	•	Body / Forms: Clean monospace (like IBM Plex Mono or Courier New) with slight CRT distortion
	•	System Voice Lines: Soft serif, slightly larger, with gentle breathing animation on punctuation
All text should have a very subtle scanline + chromatic aberration effect that intensifies during high-tension moments.

Key Visual Elements
1. CRT / Analog Effects (Always Present)
	•	Soft bloom and glow on sacred geometry
	•	Subtle screen curvature
	•	Intermittent horizontal scanlines
	•	Very faint flickering (barely noticeable)
	•	Vignette that darkens the edges
2. Sacred Geometry Overlays
	•	Golden ratio spirals, vesica piscis, metatron’s cube, flower of life patterns
	•	These appear faintly in the background and activate (brighten, rotate, connect) when forms achieve symbolic alignment
	•	Particles follow geometric paths (memory motes, thread fragments)
3. Breathing Diagrams
	•	Background contains slowly pulsing mandalas / flow charts / human silhouettes made of flowing lines
	•	They expand and contract gently, like lungs or a beating heart
4. UI Layout Philosophy
	•	Classic terminal quadrants:
	◦	Top bar: Division seal + Employee ID + Dissolution Index (always visible)
	◦	Left panel: Case profile / Worker-Unit portrait (abstract silhouette that changes)
	◦	Center: Main form area (dynamic)
	◦	Right panel: Continuity metrics, live ripple preview, taxonomy browser
	◦	Bottom: Action bar (Approve / Reject / Defer / Mercy Override)

Specific Screens – Visual Descriptions
Login / Boot Screen
	•	Full-screen Division seal slowly assembling from geometric fragments
	•	Faint rotating mandala behind the login fields
	•	Text fades in line by line with soft typing sound
Main Terminal Dashboard
	•	Dark background with drifting particles
	•	Central “window” that looks like frosted glass with glowing edges
	•	Live feed of “Continuity Weather” (subtle shifting patterns)
Form Screens
	•	Clean parchment-like panels with raised golden borders
	•	Fields light up with teal when focused
	•	When you select conflicting categories → subtle red warning glyphs appear and the geometry in background becomes tangled
	•	Successful harmonious submission → golden threads connect elements and bloom outward
Player’s Own Continuity File
	•	Most personal and disturbing screen
	•	Your portrait slowly becomes more abstract/geometric as Dissolution increases
	•	Fields rearrange themselves while you watch
End of Day Summary
	•	Beautiful data visualizations: flowing thread maps showing impact of your decisions
	•	Sacred geometry version of a performance review

Evolution Based on Player State
	•	Low Dissolution (Early game): Orderly, elegant, reassuring
	•	Medium Dissolution: Geometry becomes more prominent, colors richer, screen breathing more noticeable
	•	High Dissolution: Forms start overlapping strangely, your own face appears faintly in background patterns, text occasionally rewrites itself, geometry becomes more chaotic and beautiful

Particle & Effect Systems
	•	Memory Motes: Small glowing rectangles (like tiny papers) drifting slowly
	•	Thread Lines: Thin glowing lines connecting related form elements
	•	Glyph Bloom: When powerful decisions are made, ancient-looking symbols flare and fade
	•	Unraveling Effect: Screen edges start fraying into static when system strain is high
